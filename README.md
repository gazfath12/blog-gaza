# Gaza Alfath Blog 🚀

Personal blog modern dan minimalis untuk developer, dibangun dengan Next.js, Neon PostgreSQL, dan AI Auto Blogging.

## ✨ Fitur Utama
- **Desain Premium**: Minimalis, clean, dengan dominasi warna putih, hitam, dan aksen biru.
- **Admin Dashboard**: Kelola artikel (CRUD), kategori, dan tag dengan mudah.
- **AI Auto Blogging**: Otomatisasi pembuatan konten menggunakan Gemini AI dan GitHub Actions.
- **Markdown Editor**: Tulis artikel dengan format Markdown yang developer-friendly.
- **Dark Mode**: Dukungan mode gelap otomatis dan manual.
- **SEO Optimized**: Metadata dinamis, Sitemap, dan Robots.txt sudah terintegrasi.

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Database**: Neon PostgreSQL
- **ORM**: Prisma
- **AI**: Gemini AI
- **Automation**: GitHub Actions

## 🚀 Setup Cepat
1. Clone repository
2. Install dependencies: `npm install`
3. Setup `.env` berdasarkan `.env.example`
4. Jalankan database push: `npx prisma db push`
5. Jalankan aplikasi: `npm run dev`

Untuk informasi lebih lanjut mengenai setup AI, baca [AI_AUTO_BLOGGING.md](./AI_AUTO_BLOGGING.md).
